BOIN-ETC Shiny V5.7 Interactive UI

Built on the V5.5 Reviewed version. Core BOIN-ETC simulation and result logic are unchanged.

UI / interaction changes:
- Run button is disabled until the current inputs pass validation and BOINETC is available.
- Run button shows a loading state while a simulation is executing.
- Ready / running / attention status pill added to Study Setup.
- Preview Scenario and Reset Inputs quick-action buttons added.
- Results page includes quick navigation to Charts, Detailed Data, and Export.
- Download buttons use clearer primary/secondary visual hierarchy.
- Buttons have hover, pressed, and shadow feedback.
- Active navigation tab receives a stronger visual indicator.
- Page transitions use a short fade/slide animation.
- Simulation success/failure now also uses Shiny notifications.

Start on Windows with LAUNCH_BOINETC_APP.bat.
